Delivery that continues after the process exits.

Register an endpoint, publish an event, and drain what is still pending. The body is signed before the first attempt.

      API

      Bearer token on every /v1 route.

      01

      Register

      Create or replace a subscriber. An empty type list receives every event.

      curl -s -H "Authorization: Bearer $GHK_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"id":"lab","url":"https://example.com/hooks","secret":"sek","types":["lot.released"]}' \
  http://localhost:8080/v1/endpoints
      02

      Publish

      Required fields are id and type. data is JSON. The response includes delivery ids and drain counts.

      curl -s -H "Authorization: Bearer $GHK_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"id":"evt_1","type":"lot.released","data":{"lot":"A"}}' \
  http://localhost:8080/v1/events
      03

      Bearer

      Every /v1 route requires Authorization: Bearer and GHK_API_TOKEN. Drain accepts that header or CRON_SECRET.

      curl -s -H "Authorization: Bearer $GHK_API_TOKEN" \
  -X POST http://localhost:8080/v1/drain

      Signing

      The receiver can check the body without trusting the path.

      The header is t=<unix>,v1=<hex>. The MAC is HMAC-SHA256 of <unix>.<body> with the endpoint secret. GET /v1/deliveries/{id} returns status and attempts and leaves the secret out.

      Where it runs

      Same rules in memory, in SQLite, and on Postgres.

      Long-running server

      cmd/ghklabs stores endpoints and deliveries and drains due work about once a second. GHK_DB defaults to data/ghk.db.

      Postgres

      A DATABASE_URL that starts with postgres:// or postgresql:// selects Postgres. That is the store that survives on Vercel.

      Daily cron

      On Vercel, GET /api runs the same drain once a day. Hobby schedules cannot run more often. A SQLite file does not persist across invocations.

      Library

      webhook.Dispatcher signs and retries in memory underneath the same header. Callers still invoke DeliverOnce.
